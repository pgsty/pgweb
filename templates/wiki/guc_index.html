PostgreSQL 配置参数

配置参数（GUC）决定 PostgreSQL 运行时的行为：内存分配、预写式日志、检查点、查询规划、日志记录与自动清理都由它们控制，每一个都是 pg_settings 里的一行。本栏目收录 {{ total }} 个参数，分属 {{ group_count }} 个一级分类，覆盖 PostgreSQL {{ earliest_major }} 至 {{ latest_major }}，逐版本记下每个参数的默认值、生效方式、取值范围与说明变化。{{ earliest_major }} 是本数据集的收录基线，不代表这些参数首次于 {{ earliest_major }} 引入。
