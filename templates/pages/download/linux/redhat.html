Linux 下载（Red Hat 系列）

Red Hat 系列的常见发行版包括：

  • Red Hat Enterprise Linux
  • Rocky Linux
  • AlmaLinux
  • Fedora

这些发行版通常自带 PostgreSQL，但提供的版本由发行版决定，不一定符合您的需要。 如需选择其他受支持的 PostgreSQL 版本，可以使用 PostgreSQL 项目维护的 PGDG 软件包仓库。

PostgreSQL YUM 仓库

PostgreSQL YUM 仓库（PGDG）可通过系统的软件包管理器安装和更新 PostgreSQL，在各版本的支持周期内提供维护更新。

PGDG 仓库支持以下发行版，具体可用的系统版本与架构见下方选项：

  • Red Hat Enterprise Linux
  • Rocky Linux
  • AlmaLinux
  • Fedora*
  • Amazon Linux 2023

*注意：Fedora 的支持周期较短，可用的 PostgreSQL 版本可能较少。部署服务器时，建议选择支持周期更长的发行版。

RHEL、Rocky Linux 和 AlmaLinux 9、10 的仓库配置包会自动匹配系统的小版本，并随系统升级切换到相应仓库，无需另选小版本专用安装包。 已安装旧版仓库配置包的用户，可参阅 PGDG 更新说明，其中包含 9.6 系统的兼容处理方法。

使用发行版自带的软件包

这些发行版默认都包含 PostgreSQL。要从这些仓库安装 PostgreSQL，请在 RHEL 和 Fedora 上使用 dnf 命令：

dnf install postgresql-server

您获得的 PostgreSQL 版本取决于发行版的版本：

发行版 版本
RHEL / Rocky Linux / AlmaLinux 10 16
RHEL / Rocky Linux / AlmaLinux 9 16、15 和 13（通过模块提供）
RHEL / Rocky Linux / AlmaLinux 8 15、13、12、10 和 9.6（通过模块提供）
Fedora 44 18
Fedora 43 18

其他 Red Hat 系列发行版可能默认提供不同版本的 PostgreSQL，请向您的发行版供应商确认。

发行版仓库中常见的软件包如下。PGDG 仓库的 PostgreSQL 软件包名称通常带有大版本号，请以上方生成的安装命令为准。

postgresql 客户端程序
postgresql-server 核心数据库服务器
postgresql-contrib 额外提供的模块
postgresql-devel C 语言开发库和头文件

安装后配置

通过发行版仓库安装 PostgreSQL 后，通常还需要初始化数据库并启用服务。对于 RHEL、Rocky Linux、AlmaLinux 8–10，以及 Fedora 43、44，可执行： 

  postgresql-setup --initdb
  systemctl enable postgresql.service
  systemctl start postgresql.service

直接下载 RPM

如果您无法或不想使用基于 yum 的安装方式，yum 仓库中的所有 RPM 包也可以直接下载并手动安装。

PostgreSQL Yum 仓库中国镜像

如果您位于中国大陆，可以考虑使用腾讯云 PostgreSQL YUM 镜像。也可以使用 pig 命令行工具添加 PGDG 仓库，自动根据所在区域选择合适的镜像。 

curl https://repo.pigsty.cc/pig | bash
pig repo add pgdg
