联系我们

报告 Bug

PostgreSQL 社区始终致力于提供能够可靠存储数据的软件。如果您认为发现了 Bug，请点击下方按钮，并按照说明提交 Bug 报告。

提交 Bug 报告

如果您认为发现了安全问题，请阅读下方相关章节。

报告安全问题

如果您认为发现了安全问题，请发送邮件至 security@postgresql.org。

支持

如果您对 PostgreSQL 有一般性问题，或者正在寻求使用 PostgreSQL 方面的帮助，请访问网站的支持页面，了解可用的联系渠道。

行为准则委员会

如果您遭遇了违反 PostgreSQL 行为准则的行为，请及时向行为准则委员会报告，邮箱为 coc@postgresql.org。如果您需要对委员会某位成员进行投诉，也可以单独联系其他委员会成员。

筹款与捐赠

如需了解筹款与捐赠相关信息，包括对 PostgreSQL 相关活动的资金赞助，请访问捐赠页面，或直接联系资金管理小组，邮箱为 funds-group@postgresql.org。

用户组联络

如果您正在为 PostgreSQL 用户组寻求支持、希望创建用户组，或需要用户组相关资源，请联系 usergroups@postgresql.org。如需查看活跃的 PostgreSQL 用户组列表，请访问本地用户组页面。

媒体咨询

如需媒体咨询，请参阅媒体页面。

网站管理员

请通过 webmaster@postgresql.org 联系 PostgreSQL 网站管理员。

pg.center 网站问题

以上渠道均属于 PostgreSQL 官方社区，处理的是 PostgreSQL 本身和 postgresql.org 的事务。本站（pg.center）是社区维护的中文站点，与官方无隶属关系；译文错误、页面显示问题或功能建议，请在 pgsty/pgweb 仓库提交 issue，也欢迎直接提交 pull request。本站的版权、署名与商标说明见关于 pg.center。

联系方式

本站由 Pigsty 项目组维护，维护者冯若航。与本站相关的合作、转载或其他事宜，可通过上述仓库或 Pigsty 网站上的联系方式与我们取得联系。
