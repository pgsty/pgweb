关于 pgsql.cc

pgsql.cc 是 postgresql.org 官方网站与 PostgreSQL 手册的中文翻译站点，由 Pigsty 团队发起并维护，是一个社区项目。本站与 PostgreSQL 全球开发组（PGDG）、PostgreSQL Community Association 均无隶属关系，也不代表它们发布任何信息。

内容来源

本站的页面结构、文案与手册内容译自 postgresql.org 及其文档，随上游更新持续同步。除翻译之外，本站还补充了少量面向中文读者的内容，例如中文社区的活动、资源与镜像说明；这些补充内容在页面中会尽量标明。

译文力求忠实原文，但翻译难免存在疏漏。凡译文与英文原文有出入之处，均以原文为准。页面右上角的外链图标可前往对应的上游原文。

版权与许可

原文。postgresql.org 的网站内容与 PostgreSQL 文档的著作权归 The PostgreSQL Global Development Group 所有，依 PostgreSQL 许可证发布。该许可证允许在保留原有版权声明与许可声明的前提下自由使用、复制、修改和分发，本站的翻译与再发布即基于这一授权。

译文。中文译文是原文的演绎作品，其著作权归 pgsql.cc 的贡献者所有，自 2026 年起。为了与上游保持一致，译文同样依 PostgreSQL 许可证发布：您可以自由使用、复制、修改和分发本站的译文，只需保留原文与译文的版权声明及许可声明。

第三方内容。新闻归档中的产品公告、Planet PostgreSQL 汇聚的博客文章、赞助者与产品目录中的名称与标志，其著作权归各自的发布者或所有者，本站仅作翻译或转载，不对其内容负责。

署名与转载

转载或引用本站译文时，请同时注明原文出处与译文出处，例如： 

原文：PostgreSQL Global Development Group，https://www.postgresql.org/
译文：pgsql.cc，https://pgsql.cc/

引用 PostgreSQL 手册的译文时，建议附上对应的英文原文链接，方便读者核对。若您对译文做了修改，请注明修改之处，不要让读者误以为修改后的文本仍是本站的译文。

商标

PostgreSQL 名称与大象标志是 PostgreSQL Community Association 的商标。本站按照其商标政策，仅在指称 PostgreSQL 项目与软件时使用这些商标，并在显著位置说明本站并非官方站点。本站不以任何形式暗示获得了上述组织的背书。

Pigsty 是 Pigsty 项目的商标。页面中出现的其他产品名称与标志归各自所有者所有。

维护与参与

本站的代码基于 PostgreSQL 官方网站的开源项目 pgweb，中文站的修改公开在 pgsty/pgweb 仓库中，同样依 PostgreSQL 许可证发布。

发现译文错误、页面问题或有改进建议，欢迎通过仓库提交 issue 或 pull request。手册页面底部的“提交更正”表单会把关于英文原文的问题转交给上游文档维护者；关于译文本身的问题，请直接在仓库中反馈。
