上游[发布公告](https://www.postgresql.org/about/news/postgresql-19-released-3449/)、
[版本 JSON](https://www.postgresql.org/versions.json)和 `postgres/pgweb` 的
`d462d6c7caf21f5513a8a54944fd992341d272b1` 已交叉核对。
PG19 首次及当前发布日期均为 2026-11-19，维护截止日为 2031-11-19。

`data/yum.json` 与 APT 示例，Windows/macOS 表按供应方公布的实测平台补充。
原始索引、签名、摘要与 HTTP 回执保存在本机
