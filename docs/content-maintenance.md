# 中文内容与 SEO 维护

本文合并 2026-09-08 至 09 的 SEO、翻译和标题审阅中需要长期维护的规则。逐页提案、修订差异、抓取数据、工作簿、截图和构建副本属于审计产物；运行代码与测试不依赖它们。

## 内容与术语

- 保留现有中文译文、上游链接、模板插值与代码示例；历史新闻资料包不改写成当前版本的产品介绍。
- 按 PostgreSQL 文档术语表统一术语，例如全文检索、故障切换、排他约束、标识列、预写式日志、整页写入、可见性映射、自动清理、仅索引扫描与事务 ID 回卷。
- 数据库集簇与高可用集群、可伸缩性与可扩展性、版权与许可证按语义区分；`schema` 在数据库对象语境中译为“模式”。
- 中文与中文链接之间不因 HTML 换行产生多余空格；英文标识符、版本号及中英文边界保留必要间距。
- 表单只翻译展示标签、帮助文字和校验提示，不改模型字段、数据库值或提交协议。
- 新闻资料包和行为准则的其他语言页面保留原语言；中文行为准则旧入口复用现行正文。

## 标题、摘要与链接

- 静态页面元数据集中于 `data/page_metadata.yaml`；动态页面由各视图提供 `og`。`pgweb/core/templatetags/pgseo.py` 统一选择最终标题、摘要与 canonical，模板不重复维护另一套品牌前缀。
- 中文标题使用 `PostgreSQL 内容`，避免 `PostgreSQL：PostgreSQL…`。特性详情标明特性名称，安全列表标明版本，发布说明标明具体版本，新闻分页标明截止日期。
- 摘要来自页面正文或准确的页面介绍，使用 `pgweb/util/seo.py` 的公共提取器排除导航、代码和迁移字段；不凭空补活动发布日期。
- 新闻 URL 共用 `NewsArticle.permanenturl` / `news_url()`。纯中文标题使用 `news` 回退 slug，旧空 slug 地址保留重定向；RSS、站内链接和社交投递使用相同地址。
- sitemap 只收录规范页面：当前 PostgreSQL 手册列 `/docs/current/`，历史手册列自身版本，扩展目录列 `/ext/` 与 `/e/<名称>/`。筛选页、内部模板和兼容跳转不进入 sitemap。
- 未加载的手册不生成失效阅读链接；未加载但真实存在的历史发布说明可跳转官方同版本页面，未发布版本保留 404。
- 页头、移动导航和页脚共用 `source_url` / `source_label`；普通页默认为 PostgreSQL 上游对应地址，三方介绍页与扩展目录由视图覆盖。

## 验证与产物

修改后运行以下本地检查，并抽查本次涉及的实际页面：

```bash
.venv/bin/python manage.py check
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/python manage.py test pgweb --noinput --keepdb
git diff --check
```

源码、数据配置、维护文档和回归测试纳入 Git；一次性报告、下载或构建产物、数据库备份放在忽略的 `tmp/` 或 `reports/` 中。数据库恢复备份不能当作可重建的构建缓存删除。必要结论整理到 `docs/`，不用提交报告生成器及其依赖副本。

本地检查、Git 提交、生产部署和公网验证分别记录；归档中的历史验证结果不代表当前生产状态。
