# 教程索引素材

- `dalibo-elephant.png`：Dalibo 官方网站的独立大象标识，来自
  <https://www.dalibo.com/assets/i/favicon.ico>（实际格式为透明 PNG）。
  原图直接保存，未重新绘制，不含品牌文字与标语。
- `features-cover.webp`：使用内置 imagegen 为《PG 特性介绍》生成的索引封面，
  按 Noriyoshi Shinoda 的《PostgreSQL New Features With Examples》内容设计。
  蓝色书页逐层递进，表现 PostgreSQL 9.5–19 的十二个大版本；书名、版本范围、
  作者与译者保留在封面上。网页资源为 720 × 960 WebP，质量 90。
- `howto.svg`：以 [PostgreSQL Howto 中文站的矢量标识](https://postgres-howto.cn/images/brand/symbol.svg)
  排版的索引封面；保留原标识路径，加入书名和作译者，不作为纸书出版封面。
- 《PostgreSQL 14 内参》使用[中文站提供的原版封面](https://postgres-internals.cn/book-library/images/internals-14.png)，
  阅读入口直达 <https://postgres-internals.cn/docs/>。

## 书目信息核对

- 《PostgreSQL 14 内参》：Postgres Professional 的[原书介绍](https://postgrespro.com/community/books/internals)
  列明 Egor Rogov 原著及 Xiong Cancan 中译本；中文译本于 [2024 年 12 月发布](https://blog.vonng.com/pg/pg14-internals-cn/)。
- 《PostgreSQL How To》：[翻译仓库](https://github.com/xiongcccc/postgres-howto/)
  与[中文站来源说明](https://postgres-howto.cn/README.md)列明原作者 Nikolay Samokhvalov、
  2023 年启动及 xiongcc 翻译、解读与校订。
- 《PostgreSQL 技术内幕》：纸书以《PostgreSQL 指南：内幕探索》出版，
  ISBN 9787121357091，[出版记录](https://www.96192.com/product/detail/584199)为 2019 年；
  [中文阅读站](https://pgint.vonng.com/)以 2018 年中文译稿为主体，涵盖 PG9.x–11，另有后续版本补译。
- 《PostgreSQL 监控》：[出版信息](https://pgmon.pgsql.cc/publication/)为 2024 年；
  [作者配套环境](https://github.com/lesovsky/postgresql-monitoring-book/blob/main/playground/postgres/Dockerfile)
  使用 PostgreSQL 15。卡片标注的是配套示例环境，不将全书限定为单一版本。
- 《PostgreSQL 18 查询优化》：[出版信息](https://pgqpt.pgsql.cc/publication/)为 2026 年，针对 PostgreSQL 18。
